## Description

餐採智控是為台灣餐廳打造的採購決策工具。你可以建立食材與供應商資料、同步市場行情、比較多家報價、產生可直接傳給供應商的議價訊息。

主要功能：

- 建立餐廳常用食材與採購單位
- 匯入或快取農產品與批發行情
- 記錄多家供應商報價
- 自動比較供應商報價與 7 日 / 30 日市場均價
- 顯示供應商價格排名與價差百分比
- 產生可貼到 LINE 或訊息的議價草稿
- PRO 進階：建議目標價、年化節省預估、採購風險分數、談判槓桿建議
- 無網路時仍可查看最近一次行情快取

餐採智控的所有價差、均價與排名都由 App 內的 deterministic service 計算。AI 只協助整理與改寫議價文字，不會自行產生或修改價格數字。

本 App 提供資料整理、計算與採購溝通輔助，僅供一般營運管理參考，不構成法律、會計、稅務、採購保證或任何專業意見。公開行情可能有延遲或品項差異，實際交易仍應由使用者與供應商確認。
