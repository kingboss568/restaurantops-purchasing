# Brand Creative Prompts (給 ChatGPT 產圖/命名)

## App Title 候選

1. RestaurantOps Purchasing
2. FreshCost Command
3. Kitchen Margin Radar

## App Icon Prompt

設計一個 iOS App Icon，主題為餐廳採購與成本優化。圖像元素包含：簡化的購物籃、上升折線、價格標籤。風格要高級、乾淨、現代商業感，避免卡通感。配色使用深青綠、暖橘、象牙白，保持高對比與小尺寸可辨識。輸出 1024x1024，無文字、無邊框、無浮水印。

## Hero Illustration Prompt

製作一張 App 首頁插圖：餐廳經理在平板上查看供應商報價與市場行情折線圖，旁邊有食材箱與標籤。畫面要有專業營運決策氛圍、光線清爽、構圖偏橫向，適合 iOS 應用首頁。風格寫實扁平混合，避免擁擠。輸出 1792x1024。
